## Architecture

The project follows a modular architecture, organizing the application around its main business domains. The architecture and technologies will evolve as the project grows.

## Tech Stack

- **Language:** TypeScript (ES2025 target, ESNext modules)
- **Runtime:** Node.js
- **Build:** TypeScript Compiler (tsc) + tsc-alias
- **Testing:** Vitest with V8 coverage
- **Linting:** ESLint + TypeScript ESLint + Prettier
- **Dev Server:** tsx watch mode

## Domain Module: User

### Value Object: Email (`src/modules/user/domain/value-objects/email.ts`)

**Class:** `Email`  
**Purpose:** Immutable value object representing a validated email address

**Properties:**
- `_value: string` (private, readonly)

**Methods:**
- `static create(email: string): Email` - Factory method that validates and normalizes email
- `get value(): string` - Returns the email value
- `equals(other: Email): boolean` - Compares two Email instances

**Validation Rules:**
- Trim whitespace and convert to lowercase
- Max length: 254 characters
- Regex: `/^[^\s@.]+(\.[^\s@.]+)*@[^\s@.]+(\.[^\s@.]+)+$/`

**Error:** Throws `Error('Invalid email format')` on invalid input

### Entity: User (`src/modules/user/domain/entities/user.ts`)

**Interface:** `UserProps`
- `id: string`
- `name: string`
- `email: Email`
- `passwordHash: string`
- `createdAt?: Date`
- `updatedAt?: Date`

**Class:** `User`  
**Purpose:** Domain entity representing a user

**Properties (private readonly):**
- `id: string`
- `name: string`
- `email: Email`
- `passwordHash: string`
- `createdAt: Date`
- `updatedAt: Date`

**Constructor:** Accepts `UserProps`, validates name, sets default timestamps

**Validation:**
- Name: trimmed, cannot be empty (throws `Error('Name cannot be empty.')`)

**Getters:**
- `getId: string`
- `getName: string`
- `getEmail: Email`
- `getCreatedAt: Date`
- `getUpdatedAt: Date`
