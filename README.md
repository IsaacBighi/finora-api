
# Finora API

A personal finance management API designed to help users organize and manage their financial activities.

Finora is an evolving software engineering project focused on building a reliable, maintainable, and secure backend application.

## Project Goals

- Manage personal financial information.
- Organize income and expenses.
- Provide financial account management.
- Apply software engineering best practices.
- Build a well-structured and maintainable REST API.

## Planned Features

### Phase 1 — Core Features

- [ ] User registration
- [ ] User authentication
- [ ] User profile management
- [ ] Financial account management
- [ ] Income and expense tracking
- [ ] Financial dashboard

### Phase 2 — Financial Planning

- [ ] Custom transaction categories
- [ ] Monthly budgets
- [ ] Recurring transactions
- [ ] Financial reports
- [ ] CSV export

### Phase 3 — Advanced Features

- [ ] Organizations and workspaces
- [ ] Role-based access control
- [ ] Notifications
- [ ] Background processing
- [ ] Subscription management

## Architecture

The project will follow a modular architecture, organizing the application around its main business domains.

The architecture and technologies will evolve as the project grows.

## Development Approach

Finora is being developed incrementally. Each phase introduces new functionality and technical challenges, allowing the project to grow alongside the developer's knowledge and experience.
